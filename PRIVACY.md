# Privacy

The default CLI and web matcher make no third-party network calls. The web path holds uploaded bytes in memory for one request and does not intentionally persist them. Generated CLI outputs contain financial data and remain the operator's responsibility.

Optional AI advisory is disabled unless explicitly invoked and configured. Enabling it transmits deposit and invoice fields to the selected provider. Review that provider's terms, retention, security, and jurisdiction before use.

Do not use real customer data in issues, tests, demos, telemetry, or support requests.

Draft template - not legal advice - requires qualified counsel review before operative use.
