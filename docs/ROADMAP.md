# Evidence-led roadmap

## Implemented in 0.2.0

Accounting invariants, ambiguity preservation, explicit import profile, deterministic evidence bundle, safe exports, loopback web controls, governance, verification, and packaging.

## External validation gate

Run five de-identified shadow engagements covering at least 30 historical cleanup cases. Continue the standalone product only if difficult grouped cases exist, correct candidates are retained, review time improves, repeat use occurs, and paid behavior appears.

## Evidence-gated future work

- QuickBooks/Xero import mapping before API writeback;
- solver benchmark against `dpss` and OR-Tools;
- optional AICPA Audit Data Standards mapping;
- RFC 8785 compatibility only with official vectors;
- W3C PROV mapping without mandatory semantic-web dependencies;
- OCR only if structured exports prove insufficient;
- authenticated hosted architecture only after a separate threat model and privacy review.
